# Taxa legal (art. 406 do Código Civil) — série mensal, BCB SGS 29543

Série mensal da **taxa legal** de juros de mora brasileira (Lei 14.905/2024 → art. 406, §1º, do Código Civil: SELIC deduzido o IPCA, piso zero), calculada e publicada pelo Banco Central (Resolução CMN 5.171/2024, série SGS **29543**). Vigência a partir de 30/08/2024.

Arquivos: `taxa-legal.csv` e `taxa-legal.json` — mês, taxa do mês (% a.m.) e acumulado simples desde set/2024.

| Período | Acumulado (soma simples) |
|---|---|
| set/2024 → set/2026 (25 meses) | **17,779%** |
| out/2025 → set/2026 (12 meses) | **9,544%** |

Mês zerado: mar/2025 (SELIC − IPCA negativo → 0, art. 406 §3º).

## Como usar
Correção monetária pelo IPCA por fora; a taxa legal é só juros. Aplicar mês a mês sobre o valor corrigido (prática forense: soma simples).
